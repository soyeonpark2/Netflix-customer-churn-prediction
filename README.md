
# 🎬 Netflix Customer Churn Prediction

### Understanding Customer Behavior Through Data Analytics & Machine Learning

## 📌 Project Overview

This project focuses on analyzing customer behavior
and predicting customer churn using machine learning.

The goal is to identify patterns associated with
customer retention and provide data-driven insights
that support business decision-making.

## 🎯 Project Objectives

- Explore customer behavior and subscription patterns
- Identify factors associated with customer churn
- Visualize trends through exploratory data analysis
- Build a predictive classification model
- Evaluate model performance and business implications

## 🛠️ Tools & Technologies

- Python
- Google Colab
- Pandas
- Matplotlib & Seaborn
- Scikit-learn
- Logistic Regression

## 📊 Analysis & Methodology

1. Data Cleaning and Preprocessing
2. Exploratory Data Analysis (EDA)
3. Customer Behavior Visualization
4. Logistic Regression Modeling
5. Model Evaluation and Interpretation

## 💡 Business Value

Understanding customer churn can help streaming
platforms identify at-risk customers, improve
retention strategies, and support more effective
business decisions.
